Place your site branding files in this folder before running the restore script.

Expected names:
- logo.png or logo.svg
- favicon.ico or favicon.svg
- background.jpg or background.png
- login-background.jpg or login-background.png
- login-logo.png or login-logo.svg

The script will automatically use these files and apply them to Moodle, then clear caches and restart the site.
